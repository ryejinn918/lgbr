## 2. 구분별 종합 (기간 전체)

### A. 밑작업

1. **대상·기준:** RSS·계정·난이도·매체명 정합성 → 수집 우선순위 기준표  
2. **저장·검수:** 매체/소스/리포트 목록 DB, 본문·PDF 검수 화면  
3. **운영:** 인증, 원격 접근, 카탈로그, 프로필/테마 분리, 전 매체 last-run 보드  
4. **외부:** OAuth·서명 URL로 합의·문헌만 읽기

### B. 보고서 가공 및 인사이트 도출

1. **구조화 (7.11~16):** 장문 PDF → 단계형 파싱 → 목차 부착 헤딩 복구 → 주제 맵(Physical AI 등)  
2. **품질감사 (7.23~):** 섹터 프레임워크 적합성, 한국어 코멘트, 인용 짧은 제목  
3. **합의 파이프라인 (7.23~29):**  
   문서 압축·구간화 → **축 사람 검수** → 문헌 팩(주요/보조, 3개월) → 프레임 → **구간 주소 근거 채움** → 비교·복사·LG 어투·출처 각주  
4. **활용:** 비교 채팅, 산업 트렌드 초안용 합의 조회

### C. 수집 자동화

1. **RSS (7.9):** 섹터별 뉴스·전문매체 실측·적재  
2. **Fnguide (7.22~):** 세션 유지 브라우저 수집, fail-closed, 프로필·섹터·기간·Physical AI/AIDC  
3. **ARG (7.26~29):** 피드 + 본문, exclusive 잡  
4. **인사이트 매체 (7.29):** 삼일, Accenture, KPMG, EY, Deloitte — 목록·다운로드형  
5. **가시성:** 세션 타임라인, 매체×주간 커버리지, 통합 last-run 보드

## 4. 진행 흐름 (한눈에)

```
[밑작업] 매체·난이도·계정·DB·운영 화면
    │
    ├─→ [수집 자동화] RSS → Fnguide → ARG·인사이트 매체
    │         │
    │         ▼
    │    리포트·기사 목록·PDF·본문
    │         │
    └─→ [보고서 가공] 구조화·품질감사
              │
              ▼
         [인사이트] 축 검수 → 문헌 팩 → 합의 프레임·근거 → 초안 조회
```

기간 후반(7.28~30)에는 세 갈래가 동시에 돌아가며, **수집 범위 확대**와 **합의에 사람 검수·인용 규칙 반영**, **운영·외부 조회 정리**가 맞춰진 상태이다.
